# StreamGremlin – Gaming-PC Agent Setup

### Schritt 1: Herunterladen & Entpacken
1. Öffne das StreamGremlin-Dashboard im Browser.
2. Klicke im Bereich **Gaming-PC Companion Agent** auf **Download (StreamGremlin-Setup.zip)**.
3. Entpacke die ZIP-Datei an einen festen Ort auf deiner Festplatte (z. B. `C:\Tools\StreamGremlin` oder Desktop).

### Schritt 2: Starten
1. Starte im Ordner die Datei **`StreamGremlin.exe`**.
2. Unten rechts in der Windows-Taskleiste (im System-Tray neben der Uhr) erscheint das Gremlin-Symbol mit einem grünen Punkt.

### Schritt 3: Autostart einrichten (Optional)
* Klicke einmalig auf **`Autostart_Einrichten.bat`**. StreamGremlin startet ab jetzt automatisch beim Hochfahren von Windows.

---

### Wichtige Hinweise
* **Notaus:** **3x ESC** innerhalb von 1,5 Sekunden bricht alle aktiven Tastensperren und Effekte sofort ab.
* **Updates:** Werden automatisch im Hintergrund heruntergeladen und installiert.
* **Fehlerdiagnose & Logs:** Die Protokolldatei **`streamgremlin.log`** wird direkt neben der `StreamGremlin.exe` erstellt (oder per Rechtsklick auf das Tray-Icon -> *Logs anzeigen*). Bei Fehlern oder Fragen einfach diese Logdatei zur Diagnose posten.
