# 🎮 StreamGremlin – Gaming-PC Agent Setup (Anleitung für Streamer)

> **Keine Vorkenntnisse nötig!** Du musst weder IP-Adressen noch Passwörter eingeben.

---

## Schritt 1: Herunterladen & Entpacken

1. Öffne dein persönliches StreamGremlin-Dashboard im Browser.
2. Scrolle zum Bereich **Gaming-PC Companion Agent (Setup für Streamer)**.
3. Klicke auf den lila Button:  
   **`📦 StreamGremlin-Setup.zip herunterladen`**
4. Mache einen Rechtsklick auf die heruntergeladene ZIP-Datei ➔ **"Alle extrahieren..."** und entpacke den Ordner an einen festen Ort auf deiner Festplatte (z. B. `C:\Tools\StreamGremlin` oder direkt auf deinen Desktop).

---

## Schritt 2: Starten

1. Öffne den entpackten Ordner.
2. Mache einen Doppelklick auf:  
   👉 **`StreamGremlin.exe`**
3. Unten rechts in deiner Windows-Taskleiste (neben der Uhrzeit im Infobereich / System-Tray) erscheint nun ein kleines Gremlin-Symbol 😈 mit einem **grünen Punkt**.
4. **Fertig!** Dein Gaming-PC ist ab sofort live mit deinem Stream verbunden.

---

## Schritt 3 (Empfohlen): Autostart einrichten

1. Mache im selben Ordner einmalig einen Doppelklick auf:  
   👉 **`Autostart_Einrichten.bat`**
2. Ein kurzes Fenster bestätigt mit `[OK]`. Ab jetzt startet StreamGremlin automatisch im Hintergrund, sobald du deinen PC hochfährst. Du musst vor deinen Streams an nichts mehr denken.

---

## 🛡️ Wichtige Infos beim Zocken

* 🛑 **Panik-Notaus:**  
  Falls ein Chat-Troll in einer brenzligen Ranked-Situation kommt: Drücke einfach **3x schnell hintereinander die `ESC`-Taste** (innerhalb von 1,5 Sekunden). Alle aktiven Tastensperren und Mausschubser werden sofort abgebrochen!
* 🛡️ **100% Anti-Cheat sicher:**  
  StreamGremlin verwendet reine Standard-Windows-Eingaben (DirectInput-Scancodes). Es installiert keine Treiber und wird von Easy Anti-Cheat, BattlEye, Vanguard und VAC als normales Eingabegerät behandelt.
* ⚡ **Nie wieder Updates herunterladen:**  
  Der Agent aktualisiert sich bei künftigen Features oder Fehlerbehebungen vollautomatisch und geräuschlos im Hintergrund.
